# 한글 → Oracle SQL 생성기

한글 문장을 입력하면 **Oracle 11g 문법**에 맞는 `SELECT` 문을 만들어 주는 규칙 기반 웹 도구입니다.
인터넷·API·서버가 필요 없고, `index.html`을 브라우저로 열기만 하면 동작합니다. (폐쇄망 환경 대응)

## 사용 방법

1. `index.html`을 브라우저(Chrome, Edge 등)로 엽니다.
2. 한글로 조회 조건을 입력합니다. 예) `환자 테이블에서 이름이 김으로 시작하는 사람 조회`
3. **SQL 생성** 버튼(또는 `Ctrl+Enter`)을 누르면 SQL이 표시됩니다.
4. **복사** 버튼으로 결과를 클립보드에 복사합니다.

## 지원하는 패턴

| 종류 | 한글 표현 예 | 생성 결과 |
|---|---|---|
| 테이블 | `환자 테이블에서`, `고객에서` | `FROM 환자` |
| 시작/끝/포함 | `이름이 김으로 시작`, `폰으로 끝`, `gmail을 포함` | `LIKE '김%'`, `LIKE '%폰'`, `LIKE '%gmail%'` |
| 비교 | `나이가 30 이상`, `가격이 10000 미만` | `>= 30`, `< 10000` |
| 같음/다름 | `상태가 1인`, `구분이 A가 아닌` | `= 1`, `<> 'A'` |
| 기간 | `2026년 1월`, `2026년` | `TO_DATE('20260101','YYYYMMDD')` 범위 조건 |
| 집계 | `개수 조회`, `금액 합계`, `급여 평균`, 최대/최소 | `COUNT(*)`, `SUM(...)`, `AVG(...)` |
| 그룹 | `고객별 금액 합계` | `GROUP BY 고객` |
| 정렬 | `금액 큰 순으로`, `날짜 오래된 순` | `ORDER BY 금액 DESC` |
| 상위 N | `상위 10개` | `ROWNUM` 페이징 (11g 방식) |

## Oracle 11g 준수 사항

- 페이징은 `ROWNUM` 방식만 사용합니다. `FETCH FIRST n ROWS`, `OFFSET ... ROWS`(12c 이상 전용)는 **사용하지 않습니다.**
- 날짜 리터럴은 `TO_DATE('YYYYMMDD','YYYYMMDD')` 형식으로 생성합니다.

## 파일 구성

| 파일 | 설명 |
|---|---|
| `index.html` | UI (순수 HTML/CSS, 외부 CDN 없음) |
| `engine.js` | 한글 → SQL 변환 엔진 (브라우저/Node 공용) |
| `app.js` | UI 이벤트·렌더링 로직 |
| `engine.test.js` | 변환 엔진 테스트 (10개 케이스) |

## 테스트 실행

```bash
node engine.test.js
```

## 주의

- 규칙 기반이므로 인식하지 못한 조건은 경고로 표시됩니다.
- 생성된 SQL은 **실제 테이블·컬럼명과 대조한 뒤** 사용하세요. (한글 문장의 단어를 그대로 컬럼명으로 사용)
- 조회(`SELECT`) 전용입니다. `INSERT/UPDATE/DELETE`는 생성하지 않습니다.
