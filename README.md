# Hamsoa_Test_Repo

Wrks Coding Agent 연동 테스트용 저장소입니다.

## 목적

이 저장소는 원격 환경(Wrks Coding Agent)에서 다음 흐름이 정상 동작하는지 확인하기 위해 만들어졌습니다.

- 저장소 clone
- 파일 생성 및 수정
- 커밋(commit)
- 원격 push
- Pull Request 생성

## 구성

| 파일 | 설명 |
|------|------|
| `README.md` | 저장소 소개 |
| `hello.py` | 동작 확인용 Python 스크립트 |

## 실행 방법

```bash
python hello.py
```

---

> 이 파일은 Wrks Coding Agent가 자동으로 생성했습니다.
